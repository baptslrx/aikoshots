# AikoShots

Ton site sur 12 écrans d'un coup : iPhone SE, iPhone 15, Android, iPad, portables, écrans Full HD et 27". Chaque capture prend **la page entière**, dans le vrai moteur de Safari, à la taille exacte de l'appareil (et avec son identité mobile).

À chaque nouvelle capture, AikoShots **compare avec la précédente** et entoure en rouge ce qui a bougé : tu vois tout de suite qu'un changement de CSS a cassé le menu sur mobile.

- Adresse en ligne, site local (localhost, AikoServe) ou fichier HTML du Mac
- Mode sombre, page entière ou seulement l'écran visible
- Captures rangées dans Images → AikoShots, avec l'historique

## Installation (Mac)

Double-clic sur `macos/Installer AikoShots.command`.
